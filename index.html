MSc Computer Science dissertation Nile University, 2024

Credit Card Fraud Detection

An ensemble of unsupervised deep learning models for detecting fraud in a large-scale financial dataset.

Card transactions Large-scale financial dataset
Autoencoder
Recurrent neural network
EnsembleResults combined
FlaggedLikely fraud
Autoencoder
Learns to rebuild typical transactions. The ones it rebuilds badly are unusual, which makes them worth a closer look.
Recurrent neural network
Reads transactions as a sequence, so it can pick up patterns that only show over time.
Unsupervised
Neither model is told which transactions were fraudulent. Both learn what normal looks like from the data itself.
